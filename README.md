# AI Design Specs

This repository is design to be a general set of software engineering design specs which form the 'core' design philosophies.

This was inspired by Spec Driven Design and @github/spec-kit, but to solve the issue that whenever a new project is started, you nearly always want exactly the same development practices and code quality rules. For example I want:

 * BDD and TDD with red-green evidence
 * A preference of functional over OO or procedural
 * A human-review gate of tests before proceeding with implementation
 * etc...

This was becoming annoying to specify every time, and so the solution was to specify these in separate files and have the SpecKit constitution reference them.
